## 3. 仓库约定

### 不收任何客户工程数据

`.pic` / `.mdb` / `.csv` / `.zip` 已在 `.gitignore` 中排除。测试用**合成的 SDFF 文件**
做往返验证（`tests/conftest.py` 按格式规格反向生成字节），不依赖任何现场数据。

### 文档里的位号与描述都是虚构样例

本仓库是公开的。所有文档与测试中的位号（`P1_PT100101A01_PV` 之类）、中文描述、
路径均为**结构同形的虚构样例**——保留前缀/装置码/回路号/后缀的形态，只换具体编号，
这样格式说明依然成立而不外泄现场信息。

**格式规格、解码逻辑、实测数量级统计是真实的。**

往仓库里加内容时守住这条：不要贴真实位号、DCS 口令、客户工程名或本地数据路径。
改 Jet4 解码示例时注意 hex 与字符串要同步改并复验自洽。

### 历史只有一个 commit

首个 commit 曾包含未脱敏内容。因为「后来删掉」并不能让它从 git 历史里消失，
公开前用孤儿分支重建了历史，**脱敏前的版本已不存在**。
不要去找旧 commit，也不要从别处恢复它。

## 4. 开发环境备注

解析器本身只用 stdlib，任何 Python ≥3.10 都能跑。读点表需要 `access_parser`：

```bash
pip install -e ".[tagdb,dev]"
pytest
```

> 注意别用不带 pip 的精简 venv 跑安装——本机默认解释器可能就是这种，
> 装依赖与跑测试请显式指定一个完整的 Python（如 conda 环境的解释器）。
